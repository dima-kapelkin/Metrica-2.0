## Лендинг студии «Метрика»

- **Задача:** адаптивный лендинг для студии дизайна.
- **Что реализовано:** адаптивная сетка (CSS Grid/Flexbox), кастомный слайдер, семантическая верстка, оптимизация изображений.
- **Стек:** HTML5, CSS3, JavaScript (ES6+).
- **Как запустить:** открыть index.html или запустить локальный сервер.
